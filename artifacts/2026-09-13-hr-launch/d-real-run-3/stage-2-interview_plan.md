一、本次面试要验证什么（按岗位原文的逻辑关系排序）

A. 首要核验点：独立写出可复核的诊断记录（原文明确不允许延后）
- 为什么需要验证：材料记载他"记录过温升与重启的关系"，存在记录行为；但材料没有给出控制变量与最终根因，因此这份记录是否达到"可复核"（他人能据此重现条件、复查推理、看清结论边界与遗留未知）无法判断。
- 目标：观察他独立产出同类文档的实际水平，而非听其描述自己会写。

B. 诊断中的个人角色归属
- 为什么需要验证：简历称"负责解决现场断连"，材料明确指出未说明假设由他提出还是按资深工程师方案执行。既不能据"负责"认定独立主导，也不能认定只是执行。
- 目标：就具体一次断连事件，确认哪些行动由他做出、哪些由他人做出；归属只限定该次行动，不外推为整个项目的思路、排序或决策归属；他未提到的他人参与保持未知。

C. 四类因素的区分能力（通信 / 供电 / 固件时序 / 硬件）
- 通信：有直接线索（用逻辑分析仪排查通信重试），需确认深度。
- 供电与硬件：温升与重启的观察属跨因素线索，控制变量与根因未知。
- 固件时序：材料无相关记载，保持未知，需在面试中直接问，而不是假定缺失。

D. 两项并列基础要求
- C：有直接线索（维护 C 固件）；未知的是模块规模、复杂度、是否涉及时序敏感代码。
- 示波器：材料只提到逻辑分析仪。两者都是实测工具但观测对象不同（数字时序 vs 模拟量、纹波、掉压、上电斜率），不能互相替代地视为已证明；C 有线索也不让示波器一项连带成立。需要直接确认。
- 缺少记载不等于不会用，因此以"请说明/演示一次"而非"你是否不会"的方式提问。

E. 明确不需要在本次面试中弥补的项
- 机器人量产经验：原文是加分项，并明确允许由工业传感器、医疗设备等相邻经历提供工作样本。候选人的传感器项目落在原文所列相邻领域内，因此不安排"为何没有机器人经历"类问题；需要的是相邻经历的工作样本，而不是行业标签。
- 前三个月可由导师协助定位：这条培养条件修饰的是"现场定位"这项任务，可降低入职时对独立定位深度的要求；它不放宽"独立写出可复核诊断记录"，因此本方案对 A 不做入职后再培养的让步。

二、面试环节设计（建议顺序，可按用人方安排调整；每一环节都不是唯一可行方式）

环节 1：工作样本——独立写出一份诊断记录（建议 45–60 分钟，最贴合 A）
- 材料：一段虚构的现场间歇断连案例，含现象描述、日志片段、若干波形/时序截图、若干环境条件（温度、供电、负载变化），故意包含一到两条指向不同因素的线索与一条不充分线索。
- 交付要求（对应"可复核"的可观察要素）：现象与影响范围；复现条件（步骤、触发概率、所需设备）；已排除的因素及排除依据；当前最可能因素及理由；遗留未知项；需移交给谁、移交哪些证据。
- 为什么适合本次缺口：原文写的是"独立写出"，最直接的观察方式是让其独立产出同类文档；同时可一并看到 C 项（四类因素）的区分方式。
- 实施条件：题目、材料与时限对同岗位候选人一致；材料须虚构脱敏，不索取其前雇主可直接使用的产物；耗时控制在合理范围；评分参照由岗位专家事先拟定并试用；允许其提问澄清，记录他问了什么（提问本身是诊断思路的观察点，但不作为独立结论）。

环节 2：行为化追问——温升与重启那次记录（对应 A、C）
- 当时是怎样发现温升与重启存在关系的？观察到的具体现象是什么？
- 那次你改变了哪些条件、保持了哪些条件不变？如果条件不便控制，当时是怎么处理的？
- 你如何区分温度、供电、固件与硬件各自的影响？有哪些因素在当时被排除了，依据是什么？
- 那次最后得到的结论是什么？结论有没有被验证或复核，由谁做？
- 当时哪些问题没有解决？现在回看你会怎么补？
（说明：材料没有给出控制变量与根因，本组问题用于确认实际情况，不预设他没做控制变量、也不预设没有根因。）

环节 3：行为化追问——"负责解决现场断连"的具体分工（对应 B）
- 请挑一次具体的现场断连，说明时间、现象和处理过程。
- 那次的诊断假设是谁提出的？如果是多人提出，各自提了什么？
- 排查顺序由谁决定？依据是什么？
- 你本人具体执行了哪些步骤、用了哪些工具、得到什么数据？
- 结论怎样被验证？验证过程你参与了哪部分？
- 记录/报告由谁写、给谁看、对方据此做了什么？
（说明：归属只就该次行动确认；他未提及的其他人参与保持未知，不推断为"由他主导"或"由他人主导"。）

环节 4：工具与代码的直接确认（对应 D）
- 示波器：请说明或现场演示一次你用示波器观测的场景（例如上电时序、纹波、复位信号、掉压）；当时怎么设触发、怎么判读、结论是什么？如果这项使用较少，请说明你目前的实际熟练程度。据此区分：已熟悉 / 可短期补齐 / 目前是缺口。
- 逻辑分析仪：那次通信重试排查中，你抓了哪些信号、如何设置触发条件、如何从波形得到"重试"的判断、是否定位到重试原因。
- C 与固件时序：你维护的 C 固件规模与模块职责是什么？有没有涉及中断、时序敏感逻辑、看门狗、重连/重试状态机？（固件时序在材料中无记载，此处按开放问题问，不预设有或无。）

环节 5：岗位现实条件与协作方式（信息未在材料中出现，作为待确认信息而非评价项）
- 现场出差、客户沟通、把证据移交给对应负责人的经验与意愿。
- 与硬件、通信、固件不同负责人协作时，怎么界定移交边界与责任。
- 说明：候选人材料未涉及学历、年限、职级、动机、出差意愿、协作评价、绩效、可提供的作品清单，本环节只做信息补齐，不据缺失作负面判断。

三、评价与记录约定（面试实施时遵循）
- 每条记录写明：谁说的、指哪一次事件、材料/回答覆盖到什么程度；区分"明确说没做过""没有记录""自述做过""已由独立材料或工作样本证实"四种状态。
- 工作样本只证明该次独立产出的质量，可直接对应 A；口头描述不能替代 A 的验证结论。
- 不给总分或候选人排名；不使用与岗位无关的属性作判断。
- 面试后如需保留结果，用原始记录另行整理，本方案不得被当作已发生的面试记录。
