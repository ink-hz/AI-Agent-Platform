范围与基准：依据用户本次给出的临时岗位要求原文（虚构验证材料）。该岗位没有正式确认的长期岗位标准，本策略不改变任何长期标准，也不含录用或淘汰决定。

一、从原文重建的目标任务与条件（搜寻的落点）
1. 交付结果：让客户现场的间歇断连可被复现，并把因素归到通信、供电、固件时序、硬件四类之一，再把复现条件和证据移交对应负责人。
2. 必需且不可延后的一项：独立写出可复核的诊断记录。
3. 培养条件的适用范围：原文允许"前三个月由导师协助定位"。它修饰的是定位（复现与因素区分）这一环节，不延伸到"独立写出可复核诊断记录"，后者按原文自始要求独立完成。
4. 基础要求（并列必需）：熟悉 C；熟悉示波器。
5. 加分项：机器人量产经验；原文明确该加分可由工业传感器、医疗设备等相邻经历提供工作样本来体现。因此"机器人经历"不是门槛，缺少它不构成不合格。

二、来源假设（按任务相似性，而非公司名或头衔）
每条来源同时写相似点与差异点，均为待验证假设：
1. 工业传感器 / 仪器仪表的固件与现场支持岗。相似：C 固件、总线通信重试、现场偶发故障复现。差异：客户现场约束、量产规模与整机联调经验可能较弱。
2. 医疗设备现场服务 / 售后技术支持工程师。相似：可复核记录的书写习惯（可追溯性要求高）、多因素排除、与研发的证据移交。差异：可能偏流程化换件，对固件时序层面的自主定位深度未知。
3. 通信模块 / 无线连接（Wi‑Fi、BLE、以太网）调试或测试工程师。相似：断连、重连、重试机制、抓包与时序分析。差异：可能不涉及供电与硬件因素的区分。
4. 电源 / 电子硬件可靠性、EMC、环境应力（温升、振动）测试岗。相似：控制变量设计、复现条件构造、温升与异常关系分析。差异：固件侧改动与 C 代码定位经验可能较弱。
5. 汽车电子或工控售后诊断岗。相似：间歇性故障、现场取证、责任方归属划分。差异：领域知识与工具链差异，需评估补齐时间。
6. 培养型来源（若用人方接受）：有嵌入式课程/项目 + 实测工具使用的应届或 1–2 年经历者。原文的三个月导师协助只覆盖定位，仍要求独立写记录，因此这一来源的关键验证点是记录能力，不是年限。

三、检索与筛选线索（用于找人，不作为通过标准）
- 任务动词优先：间歇/偶发故障复现、断连、掉线、重连重试、复位/看门狗重启、根因定位、失效分析报告、现场问题闭环。
- 工具与信号层：示波器、逻辑分析仪、协议分析、串口/CAN/I2C/SPI/UART 时序、上电时序、纹波/掉压、温升。
- 语言与平台：C、裸机/RTOS、bootloader、日志与埋点。
- 证据形态优先于头衔：优先寻找能提供一份诊断/失效分析记录样本（可脱敏）的人，因为这最贴近"可复核记录"这项不可延后的要求。

四、对每位候选人需要采集的最小证据集（在联系与初筛阶段可要求）
1. 一次间歇性故障的个人叙述：谁提出假设、如何构造复现条件、如何排除其他三类因素、结论如何被他人复核。
2. 一份诊断记录样本或其结构描述（现象、条件、观测数据、排除过程、结论、遗留项）。
3. C 与示波器的实际使用场景（不是自评熟练度）。
4. 相邻行业者的加分证据：按原文允许的方式，用工业传感器/医疗设备等经历的工作样本呈现，而非要求补出机器人量产经历。

五、明确未知与不作的推断
- 本次没有任何渠道投放、简历漏斗、回应率或历史招聘记录材料，因此不能对渠道成效、市场供给紧张程度或该组合是否"难招"作判断；上述来源顺序是任务相似性推理，不是成效排序。
- 仅凭要求组合不能判定人才稀缺，也不据此建议放宽门槛。若用人方后续反馈简历量或初筛淘汰情况，可再区分需求定义、供给、吸引力、甄选流程四类解释。
- 岗位归属团队、职级、薪资、地点、汇报关系、导师资源的实际配置均未在材料中出现，保持未知；其中导师是否真的可提供三个月协助，会影响培养型来源是否成立，需向用人方确认（属可后续确认项，不阻碍本策略使用）。

六、可逆的下一步建议（供授权人员决定）
1. 先在工业传感器与医疗设备两类相邻来源上做一轮小样本触达，统一索取上述最小证据集，观察能提交记录样本的比例。
2. 同一份工作样本任务对所有来源保持一致，避免不同来源用不同难度的题目后直接比较。
3. 联系动作与话术发送由授权人员执行；本成果不含已联系的事实。
