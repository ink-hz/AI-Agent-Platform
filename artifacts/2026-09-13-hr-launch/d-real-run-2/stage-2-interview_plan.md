## 0. 方案性质与边界
- 本文是**尚未发生的面试方案**，全部内容是"计划要问、计划要看"，不含任何已发生的面试事实。执行后需另存 interview_record，并以现场原始记录为准。
- 依据：用户本次临时岗位要求（示例公司嵌入式现场诊断工程师）+ 本次提供的候选人材料（均为虚构验证材料）+ 前置候选人评估成果。**无正式确认的长期岗位标准**，因此本方案的评价参照是本次临时要求，不构成长期标准。
- 候选人材料为简历级陈述、篇幅很短、无第三方核验。方案的作用是把"材料记载了什么"推进为"可观察的行为与产物"，不是确认结论。
- 材料未记载不等于不具备（示波器、固件时序层、证据交接均属此类），面试题按**中性核验**设计，不预设不合格。
- 加分项（机器人量产经验）材料明确为"无"，按临时要求它是加分项且给出了相邻经历+工作样本的替代路径，**不作为面试淘汰题或门槛题**；下文只用它触发替代路径的样本核验。

## 1. 本次要验证什么（按优先级，附"为什么这样验"）

**V1（首要）· 在"现场断连"中的个人角色与独立提出假设的程度**
- 缺口来源：简历称"负责解决现场断连"，但材料明确未说明他是提出诊断假设者还是按资深工程师方案执行者。
- 为什么要验：临时要求允许前三个月由导师协助**定位**，所以偏执行不构成硬性不合格；但该项决定入职后需要多少辅导、多快能独立，是本次最关键的不确定项。
- 适合方式：行为化追问（区分个人行动与团队方案，需要追问决策发起、被否方案、当时替代选择），口头叙述在此类问题上信息量最大；辅以产物归属追问。

**V2（硬性）· 能否独立写出可复核的诊断记录**
- 缺口来源：有"记录过温升与重启的关系"这一书面行为线索，但同一处说明缺控制变量与最终根因，是否达到可复核标准无法判断。
- 为什么要验：这是临时要求中**不受三个月培养期豁免**的一项（培养条件只修饰"定位"，不延伸到记录交付）。属产物型能力，口头叙述难以区分本人撰写与团队产出，因此以**工作样本或既往脱敏记录**为主证据。

**V3（并列基础项）· 示波器**
- 缺口来源：材料只提逻辑分析仪排查通信重试，未提示波器。两者用途重叠但不等同（协议/逻辑时序 vs 模拟波形、电源纹波、毛刺）。
- 为什么要验：临时要求把"熟悉 C 和示波器"并列为基础，且它与供电/硬件层判断直接相关；这是与该层最贴近的工具缺口。适合仪器实操或设置级情境题，纯自评无法区分。

**V4 · C 固件的改动深度**
- 缺口来源：材料只说"维护 C 固件"，改动范围、是否触及中断/时序相关代码未知。
- 适合方式：代码级情境追问 + 具体改动实例（可脱敏），必要时看一段代码走读。

**V5 · 四层分层归因的覆盖面**
- 现状：通信层有线索；供电/热有观察相关性的线索但归因结论未知；**固件时序、硬件两层材料无记载，未知**。
- 适合方式：情境题（给同一现象要求分层收窄），观察排除逻辑而非结论正确。

**V6 · 把复现条件与证据交给对应负责人**
- 现状：材料无记载（既未记载做过，也未记载没做过）。
- 适合方式：行为题 + 情境题；重点看交接内容的可用性（对方要能据此复现/定位），而非沟通风格。

## 2. 面试结构（建议 3 个环节，共约 150 分钟，可拆两次）

### 环节 A · 工作样本（60 分钟，主证据，对应 V2、V5）
- 材料统一给定，与同岗其他候选人可比：一段间歇断连的现场情境（设备日志片段 + 一段协议时序/波形截图 + 现场约束如无法长时间停机、只能带便携仪器、客户端在户外高温环境）。
- 交付要求（限时书面）：
  1) 可重复触发的复现条件（含所需设备、时长、判定标准）；
  2) 已可排除哪几类原因、依据是什么；哪几类仍存疑；
  3) 控制变量设计（同批次对照、恒温/降温、降压或降载、替换线束等任选，需说明为何选它）；
  4) 还需谁配合、验证什么、你交给对方哪些材料。
- 评价参照（分档为行为描述，不合成总分）：
  - 较高：复现条件他人可照做；排除依据与观察对应；变量设计能隔离至少两层；交接内容对方可直接执行。
  - 中等：复现条件基本可行但缺判定标准；排除逻辑部分依赖直觉；交接偏结论、缺证据。
  - 较低：只给结论或只列可能原因，无复现路径与排除依据。
- 不看排版、不看文档美观；不索取可直接用于公司的产出，情境为虚构脱敏。
- **替代路径（负担更小，二选一即可）**：接受其提交一份既往脱敏诊断记录。若走此路，必须追问哪些段落由本人撰写、当时谁审阅、记录发布给了谁——否则独立性仍未被核验。

### 环节 B · 行为化追问（45 分钟，对应 V1、V4、V6）
围绕其本人经历，按"情境—他/团队各做了什么—依据—结果—复盘"记录原话：

1. 温升-重启案例（V1+V2 核心）：
   - 最早是谁提出"温升可能与重启相关"的？当时看到什么现象让你（或对方）想到这一点？
   - 你当时怎么控制其他变量？（若答不上，追问：如果只能借到一台恒温箱和一批同型设备，你会怎么安排对照？）
   - 那份记录是你独立写的哪些部分？给了谁看？对方据此做了什么？
   - 为什么最终没有写出根因？当时缺的是条件、时间、权限，还是方向不明？现在重来会先做什么？
2. 通信重试排查（V1+V5）：
   - 用逻辑分析仪时，你的抓取点、触发条件是自己定的还是别人指定的？
   - 有没有一次你的假设被证伪？怎么发现的、接着换了什么假设？
3. C 固件维护（V4）：
   - 举一处你改过的、涉及超时/重连/中断或定时的代码，改动前后的行为差异是什么？怎么验证没引入新问题？
   - 有没有遇到过"改固件掩盖了硬件问题"或反之的情形？
4. 交接（V6）：
   - 最近一次你把一个未定位完的问题交给硬件/电源/上层软件同事，你给了什么材料？对方回来问了什么你没提供的？

### 环节 C · 仪器实操或设置级核验（30 分钟，对应 V3，并回补 V5 的硬件/供电层）
- 现场或远程共享设备：请其为"抓一个偶发毛刺 / 一次复位瞬间"设置触发方式（边沿/脉宽/欠压触发、单次捕获、预触发深度）、探头与接地（地弹、探头带宽与负载效应）、时基与带宽/采样率取舍。
- 追问：什么情况下该用示波器而不是逻辑分析仪，反之亦然？要判断"电源纹波是否导致复位"，你会怎么测、测哪几个点、看什么阈值？
- 若无实验条件：改为口述设置方案 + 给出一张含毛刺/下冲的波形请其解读。**注意**：口述方案属较弱证据，结论需相应降级为"有相关线索"。

## 3. 一致性与公平安排
- 环节 A 的情境材料、时限、交付要求与评价参照对同岗所有候选人保持一致；环节 B 中针对本人经历的追问属围绕个人证据缺口的中性追问，**难度不同的个性化问题不能直接与他人相加比较**，只用于解释本人的独立性证据。
- 建议 2 名评估者（含一名熟悉现场诊断的岗位专家）各自先独立记录具体回答与行为、形成判断，再讨论理由与分歧，不先对分数。
- 提前告知候选人：环节、时长、是否需要设备、可自带脱敏材料、无需准备公司相关方案。
- 题目与评价参照本次为首次使用、未经试用，属自制工具，**不得称为已验证测评**；执行后应记录歧义与时长问题以便修订。
- 只记录岗位相关行为与产物；不评价与任务无关的属性。

## 4. 执行后如何下结论（防止结论强于证据）
- V2（独立写出可复核记录）只能由**产物**支撑：工作样本或经追问确认作者归属的既往记录。若两者都未取得，该硬性项应记"仍未核验"，不能用面试表达好来替代。
- V1 若追问后仍无法区分本人与资深工程师的角色，应记"未知"，而不是记为"偏执行"或"具备独立性"；并说明这决定辅导投入而非直接淘汰。
- 一次工作样本表现良好只支持"在该任务条件下的一次观察"，不支持"稳定具备分层诊断能力"；后续可用参考人访谈或其项目内他人可佐证的产物补强，独立性证据仍以本人产物最直接。
- 加分项无机器人经历这一点，在结论中仍按加分项处理；相邻经历替代路径是否走通，取决于环节 A 的样本，而非行业标签。
- 三个月导师协助只适用于"定位"，评价时不得把"记录交付"也按可延后处理。

## 5. 尚需用人方确认的实施条件（不影响方案主体，可并行推进）
- 能否提供环节 A 的情境材料（脱敏日志/波形）与评审人；
- 环节 C 是否有可用设备与远程共享条件；
- 是否接受"提交既往脱敏记录"作为环节 A 的替代路径；
- 面试轮次是否需要与用人经理的其他环节合并。
