## 0. 范围与基准
- 基准：用户本次给出的临时岗位要求（示例公司，虚构验证材料）。该岗位**没有正式确认的长期标准**，本策略不改变任何长期标准。
- 目标任务（从原文重建）：①复现客户现场的间歇性断连；②在通信、供电、固件时序、硬件四类原因间做隔离；③产出可复核的诊断记录并移交对应负责人（跨职能交接）。

## 1. 搜寻口径：把要求翻译成可搜的任务线索
必需能力（原文列为基础/必须）：
- C 语言（嵌入式固件语境）；
- 示波器使用（信号级观测）；
- **独立**产出可复核的诊断记录。注意：原文允许前三个月由导师协助的是"定位"，记录撰写没有被允许延后，因此这项应作为筛选与核验重点，而不是入职后再看。

加分项（不作淘汰依据）：
- 机器人量产经验；原文明确其可由工业传感器、医疗设备等**相邻经历提供工作样本**替代。因此"无机器人经历"不构成筛除理由，只降低加分权重。

可搜关键词/线索（按任务而非公司品牌）：间歇性故障 / 偶发断连 / 复现条件、故障隔离、示波器与逻辑分析仪抓时序、UART/SPI/I2C/CAN/以太网重试与重传、供电纹波与掉压、上下电时序与看门狗复位、温升/环境应力与失效相关性、FA（失效分析）报告、8D/DOE、客户现场支持与升级（escalation）。

## 2. 人才来源假设（每类同时记相似性与差异，均待验证）
1) 工业传感器 / 仪表现场与售后工程
- 相似：现场偶发失效复现、总线通信排查、与研发交接证据。
- 差异：可能缺机器人量产节拍与产线约束知识（属加分项，可学）。
2) 医疗设备维修 / 调试与售后技术支持
- 相似：可追溯记录习惯强（受行业记录规范驱动），信号级排查。
- 差异：可能长期在既有故障树内作业，自主提出新假设的机会较少 → 需核验"提假设 vs 按方案执行"。
3) 通信模块 / 网络设备 / 车载电子的现场应用工程（FAE）与故障分析
- 相似：断连、重试、误码、供电与EMC干扰的分层隔离。
- 差异：可能偏应用配置而非固件层，C 深度需核验。
4) 测试、可靠性与环境应力工程（HALT/温循/EMC 实验室）
- 相似：控制变量、可复核实验记录、复现条件描述。
- 差异：可能缺客户现场沟通与实时压力下的取舍经验。
5) 机器人 / 自动化设备 NPI 或产线设备维护（加分项来源）
- 相似：直接覆盖加分项与量产语境。
- 差异：产线故障常有固定处置流程，个人诊断推理与记录质量仍需工作样本验证。
6) 培养型来源（若用人方接受）：具备扎实 C + 示波器基础、有课程/项目级故障排查作品的应届或 1–2 年经验者。原文提供三个月导师协助，但仅覆盖"定位"；此来源的主要风险在记录独立性，需以工作样本前置验证。

## 3. 筛选与初筛提问（材料层）
优先看简历中是否存在：具体一次偶发故障的**复现条件描述**、使用了哪些观测手段与触发设置、如何排除同时存在的多个可疑因素、记录/报告最终交给了谁并被谁复核。
初筛应中性追问（不预设答案）：该次排查中"假设由谁提出"、"变量如何控制"、"根因如何被确认"。这三问直接对应本岗最难替代的必需项。

## 4. 明确区分：材料支持的线索 vs 仍需核实的假设
材料支持：目标任务、四类因素隔离、记录独立性为必需、加分项及其相邻经历替代路径。
需用人方澄清（不影响本策略成立，可并行）：
- 现场出差比例、客户类型与授权范围（能否要求客户配合复现）；
- 导师资源实际容量与"协助定位"的边界；
- 与固件、硬件、供电负责人的移交流程与文档模板（决定"可复核"的具体标准）；
- 薪酬、地点、值班安排等吸引力条件。
需市场证据核实：上述各来源的实际供给与响应率。**本策略不据要求组合推断市场稀缺，也不建议在此阶段放宽任何门槛**；若后续漏斗出现异常，应先按要求校准视角区分需求定义、供给、吸引力与流程误杀四类解释。
