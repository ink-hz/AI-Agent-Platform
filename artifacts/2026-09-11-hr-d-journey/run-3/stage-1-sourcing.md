## 一、先把要求还原成任务与证据（要求强度按原文保留）
- 业务结果：让客户现场的间歇性断连从"无法解释"变成"有复现条件与可归属证据"。
- 关键任务：①在现场/实验室复现间歇断连；②在通信、供电、固件时序、硬件四类因素之间做区分与排除；③把复现条件与证据交给对应负责人（含跨职能交接与表达）。
- 原文的必需项：熟悉 C 与示波器（表述为"基础"）；**独立写出可复核的诊断记录**。
- 原文的培养条件（限定范围）："前三个月可以由导师协助定位"只修饰故障定位这一项，不延伸到诊断记录——记录从一开始就要求本人独立产出。
- 原文的加分项：机器人量产经验；并明确可由工业传感器、医疗设备等相邻经历以工作样本替代。因此"无机器人经历"不是淘汰理由，只是需要用相邻经历的工作样本补证。
- 说明：本次要求文本内部没有出现"既列必需又列加分"的自相矛盾，因此不需要为要求强度向岗位方澄清；需澄清的是环境条件（见第四节）。

## 二、来源假设（每类同时写相似性与差异，均为待验证假设）
1. 工业传感器 / 医疗设备的固件或售后诊断岗（原文点名的相邻领域）
   - 相似：现场间歇故障、通信重试、可靠性与可追溯记录习惯（医疗类通常有较强记录要求）。
   - 差异：机器人量产的节拍、批量一致性与产线约束可能陌生；医疗领域记录风格偏合规，可能与工程诊断记录侧重不同。
2. 汽车电子 / 通信模块 / 网络设备的现场问题分析、FAE、售后技术支持
   - 相似：客户现场压力下复现偶发问题、协议层（CAN/RS485/UART/以太网/无线）重试与丢包分析、责任归属交接。
   - 差异：部分 FAE 以话术与客户关系为主、动手取证深度不足；需看是否本人操作仪器、是否本人提出假设。
3. 硬件测试 / 可靠性 / EMC / 环境试验工程师
   - 相似：控制变量、温升与电源边界、间歇失效的加速与复现方法论最接近本岗位核心。
   - 差异：C 固件与时序调试的代码侧能力可能弱；需核对固件层证据能力。
4. 产线 NPI / 制造异常分析（DFM、良率异常追溯）
   - 相似：批量数据中定位偶发失效、跨供电/机构/软件归因、写异常分析报告。
   - 差异：客户现场情境与单台偶发问题的取证条件不同。
5. 培养型来源（应届/1–2 年）
   - 可看课程与项目中的示波器/逻辑分析仪实操、协议分析、失效排查作业与记录原件；不把成熟人才的年限门槛原样套用。因原文只允许"前三个月定位有导师"，记录独立性仍是入职即要求，需以工作样本验证。

## 三、可用于筛选的能力线索（材料支持的，非头衔）
优先寻找可提交/可复述的产物与个人角色，而不是公司品牌或行业年限：
- 有一份本人写的故障分析或诊断记录（现象、假设清单、复现步骤与条件、控制变量、排除依据、结论与交接对象）。
- 描述中能区分"我提出的假设"与"按他人方案执行"。
- 仪器使用具体到测什么：示波器测供电纹波/上电与复位时序/信号完整性；逻辑分析仪测协议时序与重试——两者不可互相替代地当作同一证据。
- 有过"偶发/间歇"而非"必现"故障的处理经历（间歇性是本岗位难点）。
- 跨职能交接经历：把结论交给固件、硬件、电源或供应商并推动闭环。

## 四、仍需用人方或市场证据核实的假设（不据此放宽或加严门槛）
- 现场出差比例、客户现场的独立面客程度、是否需要单人到场决策。
- "可复核的诊断记录"是否已有模板/评审人，导师资源是否确实存在（这直接决定培养假设成立与否）。
- 目标通信协议与硬件平台范围、是否涉及无线；是否需要产线/整机联调权限。
- 薪酬、地点、职级与发展路径的吸引力；现有漏斗（若有）在哪一环流失。
- 本策略不对市场稀缺程度作判断：仅凭要求组合无法推断供给多寡，需要投递量、合格率与退出原因等实际渠道数据才能评价。

## 五、建议的搜寻与验证动作（可逆、可观察）
- 用任务语言而非头衔检索/沟通：间歇断连、偶发复现、根因定位、通信重试、上电时序、温升复测、诊断报告。
- 对相邻行业候选人统一提供同一份工作样本（见下），以补证迁移；负担控制在合理范围，不索取可直接商用的产物。
- 抽样复核被初筛淘汰的相邻行业材料，检查是否因"无机器人经历"这一加分项被误杀。
- 记录每条渠道的假设与结果；在没有实际投递与沟通记录前，本文档只是策略假设，不能称为渠道成效，也不代表已联系任何人。

## 六、与甄选衔接的共同核心
所有候选人使用同一组核心题与同一评价参照：①一次偶发故障的复现设计（情境题）；②四类因素的区分优先级与依据；③本人写过的诊断记录讲解（行为题）；④示波器/逻辑分析仪实操小任务。围绕个人证据缺口的中性追问可以不同，但难度不同的个性化题目不直接相加比较。
