# 智元集团招聘集合：从模型能力到现场可交付的责任区别

本目录的“智元”指数据源 `agibot` 汇集的招聘记录，包含标题明示的子公司与业务部，不是智元本部或单一用人团队的样本。原文有觅蜂、酷拓、临界点、擎天租、智鼎“子公司”标记，以及 Genie、通用、灵犀“业务部”标记。它们是招聘归属线索，尚不足以核实法律主体、汇报链或劳动合同主体；未标记的岗位归属待核，不能默认归入本部。因此 1,539 是这一招聘集合的岗位身份总数，不能当作本部样本量，也不能通过简单减去具名子公司记录数得出本部数量。

搜寻数据混合策略、数据价值评估或空间表示研究人才时，Q9 所引觅蜂预训练与空间智能岗位是明确入口；同篇的 Ego 数据价值实习岗未明示子公司归属，不将其归给觅蜂。灵犀的 Agent/tool 接口与 Genie 的工业应用/MES 是跨业务部比较，不证明属于同一团队或上下游项目。向候选人核实经历时，应保留具体岗位及原文归属，再核实用人团队；薪酬、面试流程与汇报关系均不能从集团名称转移过去。

团队通读本包全部 1,539 个岗位身份对应的已取得正文，原始渠道共 1,561 行。50 个岗位职责与要求均空，另 5 个只有 `/`，无法凭标题补出任务；其余正文也可能有未填项目或字段错位。完整口径、分段阅读与来源见 [阅读台账](read-ledger.md)。

先看 [Q9 技术意图](q9-technical-intent.md)。数据供应合格不等于能提高模型，流式响应被取消不等于交互任务已经恢复，动作模型也不能取代全部控制、业务与物理可靠性责任。这些关系用于区分候选人的实际贡献，不能拼成已运行的组织或系统架构。
