# 2026 Q4 SDK 禅道工作队列实施计划

> **For agentic workers:** Use the executing-plans skill to implement this plan task by task. Steps use checkbox syntax for tracking.

**Goal:** 从原 Excel 校准并启用禅道的 2026 Q4 原生计划、来源模块和真实待评审工作队列，保留 #3–#69 的身份、正文和负责人。

**Architecture:** 一次性工具读取固定 SHA 的原 XLSX 和固定行→ID 清单，通过个人禅道会话调用原生计划、模块、计划关联、批量编辑、撤回评审动作；每次动作前后读回并检查受保护字段。默认只读，分步骤显式执行，支持按当前状态幂等续跑。隔离副本先验证完整场景，生产只运行同一工具与同一输入。

**Tech Stack:** Python 3.11、openpyxl、httpx、pytest、ZenTao OSS 22.6、MariaDB 10.6。

## Global Constraints

- 原 XLSX SHA-256 固定为 `402030f9a76fb966b23fc6c9ad843d5f9abd85bcdce1d685835440ae6c51b7d0`，仅“2026年Q4上线版本”工作表，67 任务、16 栏目、8 超链接。
- 使用 `backend/tools/sdk_q4_manifest.json` 的固定行→需求 ID，要求 ID 集合精确为 #3–#69；不创建或删除需求。
- #1、#2 是测试记录，不关联 Q4 计划。原表不含提出人、评审人或完整验收标准，不推断这些事实。
- 生产不运行 `nginx -t -c` 或 `nginx -T -c`；本次不改 Nginx、平台镜像或行政服务。
- 生产写入前保留数据库/数据卷备份，逐条检查人工改动；每次执行记录动作与回读摘要。未知响应停止，不盲重试。
