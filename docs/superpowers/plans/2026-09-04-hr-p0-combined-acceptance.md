# HR P0 Combined Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove, release, and production-accept the combined HR P0 flow: Panorama research plus recruiting conversation, Position/JD/JR confirmation, resume analysis, and candidate-specific interview-question PDF.

**Architecture:** Deterministic fixtures prove contracts locally; one controlled live run proves the real MetaBot/web-research/Artifact path; production acceptance verifies the business page, PostgreSQL/Flywheel evidence, attachment preview/download, and disk/release discipline. This plan does not add product behavior except narrow fixes uncovered by acceptance.

**Tech Stack:** pytest, Vitest, Vite, PostgreSQL, Docker, existing cloud deploy/acceptance scripts, agentops-controlled executor, MetaBot HR runtime.

## Global Constraints

- Execute only after both `2026-09-04-hr-p0-recruiting-loop.md` and `2026-09-04-hr-p0-panorama-intelligence.md` pass their focused acceptance tests.
- Use only compliant synthetic or fully de-identified resume fixtures.
- Do not add mock resume generation to the product UI.
- Only release Platform and `metabot-hr` components changed by these plans; do not modify Platform Nginx Server Blocks, `/office/`, FAE, VOC, Marketing, administrative applications, or unrelated services.
- Before deployment run `df -B1 / /data`; refuse deployment below the documented 25 GB/20 GB/75% gates.
- Stage only in `/data/staging/<application>/<deployment_id>/` and clean only that exact directory through `trap` on success or failure.
- Releases contain code/build output only; no `data/`, uploads, logs, indexes, databases, `.venv`, `node_modules`, or caches.
- Keep current plus two rollback releases/images; archive no more than ten releases or thirty days, whichever is stricter.
- Do not send a real business message without owner confirmation during acceptance.
