# 岗位全工作流展示

用户要求修正只占左侧的岗位目录，并提供真实岗位全工作流。沿用隔离工作树与当前发布授权；产品设计以根架构/工作流文件为准。

1. 新增 HrToolService.position_results 与现有 HR result router 的按岗位 GET：owner 与真实 turn scope 校验，稳定分页，不复制成果，不以会话绑定定位岗位。测试真实会话/worker签名保存后可按岗位读取、错岗位与撤权拒绝、分页不重复。
2. HrPositionIndex 完整宽度可筛选目录，含归档岗位可读；点击真实详情路径。新增 HrPositionWorkflow：总览及完整阶段导航，复用官网/标准/候选人/文件组件；HrSavedResultCard 复用对话成果与确认/继续引用动作。缺少记录与读取失败分开。
3. 接线 HrWorkspacePage：从岗位目录进入详情，继续动作调用已有 fill 保留真实范围与编辑/发送控制；不恢复旧任务端点。样式独立作用域，连续毛玻璃背景、深色文字、窄屏折行。
4. 相关 HTTP → 组件导航/结果引用 → 最终构建；浏览器当前没有连接，不以 DOM 测试冒充视觉验收。只发布新接口模块/静态资源，保留其他运行服务；记录交付。
