# SDK 简洁工作区与自动开通实施计划

## 目标与边界

`https://agent.orbbec.com.cn/sdk` 提供需求、任务、测试、发布四个直达入口。现有钉钉登录员工在 SDK 或已授权协作部门内时，首次点击自动获得个人禅道账号。禅道保存业务记录；完整页面仍位于独立浏览器源。首版仅收敛平台入口与禅道权限组，不改造禅道内页的布局、字段或全局导航。

生产服务器不执行 `nginx -t -c` 或 `nginx -T -c`。本轮无 Nginx 配置变更，不运行 Nginx 校验或重载。页面最终交互由业务方按 `AGENTS.md` 验收。
