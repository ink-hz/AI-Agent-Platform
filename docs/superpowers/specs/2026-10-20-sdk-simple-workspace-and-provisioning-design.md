# SDK 简洁工作区与自动开通设计

## 背景与目标

SDK 团队目前从 `https://agent.orbbec.com.cn/sdk` 进入完整禅道。平台钉钉会话已能换取个人禅道会话，但平台所有者必须先逐个在禅道创建用户并绑定账号。用户希望日常只看需求、任务、测试和发布，且合格员工首次进入时自动拥有个人账号。

首版让 `/sdk` 成为简洁的个人工作入口，禅道仍保存需求、任务、用例和发布记录。员工的写操作在个人禅道会话中完成，确保禅道显示真实操作人。现有平台 SDK 服务账号只用于受限读取和集成，不代替员工做个人写入。CSV 来源页与旧候选证据页不恢复为日常入口。

## 准入与账号

平台已验证的活跃钉钉员工才可申请进入。准入策略包含 SDK 部门及显式配置的协作部门（含子部门），并保留已有 `sdk.members` 授权。部门策略需要配置具体目录部门 ID，空列表不授予新员工权限。目录处于硬过期、人员已停用或身份不确定时，停止新建账号与签发登录票据。

首次进入时，用平台不可变的 `internal_user_id` 派生禅道账号 `sdk_<UUID 去连字符>`；账号名不取显示姓名或邮箱。现有经人工核对的绑定继续使用原禅道账号，不重建。平台以专用、私网可达的禅道建号凭据创建新账号，设置随机不可见口令、当前目录显示名及 SDK 最小权限组；只在禅道确认账号存在且权限正确后写入唯一绑定，再签发单次票据。建号超时或响应不确定时保持 `待核对`，下一次请求先核对同一个确定账号，不盲目再创建。两个并发首登只允许一个执行建号，另一请求读取结果或收到明确的进行中状态。禁止自动认领任何名称相似的旧账号。

账号被移出准入部门或停用时，平台立即停止签发新票据；同步任务撤销其 SDK 禅道权限。既有禅道会话的即时失效能力须先通过隔离实例验证；未验证前不能宣称即时单点退出。人工已有绑定在权限收回时保留审计记录，不自动删除禅道历史。

## 简洁工作入口

`/sdk` 显示四个清晰入口：需求、我的任务、测试、发布；首页优先显示本人待处理项和最近需求。每个入口只请求固定的目标标识，由平台将目标绑定到 45 秒单次票据；消费后仅跳转到服务器端固定映射的禅道站内地址。浏览器不能提供任意 URL。用户首次点击时先完成自动开通，再进入相应个人页面。

禅道内为 SDK 权限组配置精简的公共导航、需求/任务/用例列表列与简洁表单；仅显示团队实际使用的产品、执行和模块。管理员仍能进入完整后台。配置必须在隔离的禅道 22.6 实例中确认可行，再备份生产数据和配置并应用。若版本不支持某项全局简化，入口仍能准确跳到个人工作页面，不能以改禅道源码或注入脚本替代。

完整禅道保持独立浏览器源，不代理到主平台同源 `/sdk/`。公开企业子域名 `sdk.orbbec.com.cn` 的 DNS 和证书尚未具备，域名切换作为独立发布门槛；此功能不依赖把完整禅道放在主平台源上。

## 边界与验收

后端测试覆盖活跃员工、部门准入、原有 SDK 授权、离职/硬过期、既有绑定、首次建号、并发、账号冲突、禅道超时后的核对、权限组分配、票据目的地白名单和重放。真实禅道 22.6 隔离实例验证 API 创建、权限与个人会话归属。生产发布前核对部署镜像准确提交、数据库迁移、原有账号映射和备份；发布后验证真实钉钉身份的首次进入及复登、需求/任务操作人、权限撤销、平台及行政服务静态文件完整性。浏览器交互最终由业务方按仓库约定验收。
