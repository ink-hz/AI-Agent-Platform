# Agent 大脑首页简化设计

## 背景与决策

当前 Agent 大脑首页同时展示眉题、大号标题、能力说明、AI 工程笔记入口、任务输入框、限制说明和三张示例卡片。信息层级过多，输入框没有成为唯一明确的主操作。

本设计参考 DeepSeek 和现有 AI FAE Agent 的简洁对话首页：左侧承担会话历史，主内容区聚焦输入与发送。它覆盖 `2026-08-27-ai-notes-home-entry-design.md` 中“AI 工程笔记入口位于说明文字之后、任务输入框之前”的位置约定；AI 工程笔记的路由、阅读工作区、权限和内容接口保持不变。

## 首页结构

Agent 大脑新对话首页保留三部分：

1. 左侧现有会话栏，包括新建对话和历史会话。
2. 主内容区右上角的次级链接 `AI 工程笔记 →`。
3. 主内容区中央的紧凑标题 `Agent 大脑` 和任务输入框。

删除以下首页内容：

- 眉题 `把原始需求直接交给它`；
- 标题下方的能力说明；
- 输入框下方的首版能力限制说明；
- 三张任务示例卡片。

输入框原有占位文字、提交按钮、超长校验、只读状态、失败提示和重试能力继续保留。首页不增加欢迎语、宣传语、推荐任务、图标卡片或悬浮入口。

## AI 工程笔记入口

- 入口位于主内容区右上角，不进入产品顶部导航，也不放在输入框附近。
- 入口属于页面级辅助操作，使用小号品牌色文字，不使用卡片、阴影、角标或固定悬浮效果。
- 链接随页面内容正常滚动；桌面端与主内容区右边界对齐。
- 窄屏下入口位于标题上方靠右，保留足够点击高度，不遮挡标题、输入框或移动端会话菜单。
- 入口继续使用真实 `/ai-notes` `href`、平台部署前缀和客户端导航，并保留修饰键、新标签页与键盘访问行为。
- 仅新对话首页显示入口；具体对话页和其他页面不显示。

## 视觉层级与响应式

- 缩小当前首页大标题，使其成为输入区标识而不是营销 Hero。
- 主内容区使用更克制的垂直留白，输入框成为页面最大、最明确的视觉对象。
- 输入框继续沿用平台既有边框、焦点状态和提交按钮，不仿制 DeepSeek 或 FAE Agent 的品牌样式。
- 桌面端保留现有左侧会话栏；不把输入框固定到视口底部。
- 移动端按“笔记入口、标题、输入框、错误状态”的顺序自然排列，不增加悬浮按钮。

## 组件与数据流

- `BrainPage` 删除眉题、能力说明、限制说明和示例按钮，只保留标题、笔记入口、输入表单及其状态反馈。
- 笔记导航回调和提交数据流保持不变；本次不修改 API、路由、Conversation 创建或错误分类。
- `BrainWorkspacePage` 继续只在新对话状态渲染 `BrainPage`，因此具体对话页不会出现笔记入口。
- 样式只调整 Agent 大脑首页相关选择器，不改变 AI 工程笔记阅读页、专业 Agent 页面或管理中心。

## 错误与边界

- Agent 大脑不可用、网络失败、输入超限和账号只读时，现有错误提示与禁用行为保持不变。
- AI 工程笔记不可用时，入口仍可点击，由目标页显示现有模块级错误，不影响首页和对话创建。
- 当前 AI 工程笔记没有已发布文章不影响入口位置和首页结构。

## 验证

- `BrainPage` 测试确认被删除的眉题、说明和示例不再渲染。
- `BrainPage` 测试确认标题、输入框、提交按钮、笔记链接及导航行为继续存在。
- `BrainWorkspacePage` 测试确认笔记入口只出现在新对话首页。
- 样式测试确认入口位于右上角、没有固定悬浮，并覆盖窄屏布局。
- 前端全量测试和生产构建必须通过。

## 非目标

- 不重做左侧会话栏、对话详情页或全局顶部导航。
- 不修改 Agent 大脑能力、模型、提示词、API 或运行状态展示。
- 不迁移、清洗或发布 AI 工程笔记文章。
- 不增加附件、搜索、模式切换或快捷指令。
- 设计提交本身不执行生产部署。
