# 禅道直接承载 `/sdk/` 设计

## 决定与目标

`https://agent.orbbec.com.cn/sdk/` 改为禅道 22.6 的完整界面。现有 SDK React 工作台退出该公网路径；禅道现有数据库、个人账号、Q4 需求和权限组原位保留。平台仍提供钉钉身份、部门准入和个人禅道免密会话，不再复制禅道的需求、任务、Bug、用例、版本和发布操作界面。

浏览器访问 `/sdk/` 时，平台验证钉钉会话及 SDK 准入，使用已有 `sdk-sso` 专用入口取得该员工的禅道会话，设置仅用于 `/sdk/` 的 `zentaosid`，然后重定向到 `/sdk/index.php?m=my&f=index`。未登录者进入平台登录页，登录后回到 `/sdk/`。直接访问 `/sdk/` 下的其他路径也需先通过平台身份及 SDK 准入检查。身份失效后不继续暴露禅道页面。

## 路由与部署

- 禅道容器设置 `ZT_WEB_ROOT=/sdk`；本地同版本镜像已验证 `/sdk/`、`/sdk/index.php` 和 `/sdk/api.php/v2/` 路由存在。正式切换前用当前加固镜像、备份副本和独立容器核对登录、静态资源、表单、附件与跳转。
- 共享代理只改 `/sdk` 和 `/sdk/` 的路由及该路径的安全头：`/sdk` 重定向至 `/sdk/`；精确 `/sdk/` 转发平台免密入口；其余 `/sdk/` 转发本机回环端口的禅道。保留平台 `/api/`、`/office/`、行政静态资源和其他服务路由原状。
- 平台入口和禅道代理均不向禅道转发 `Authorization`。禅道响应 Cookie 路径限制为 `/sdk/`；平台钉钉 Cookie 可能随同域请求到达禅道代理，必须在边缘过滤，只转发禅道允许的 Cookie。上传大小沿用禅道原上限，不沿用旧 SDK 页面 1 MiB 上限。
- 代理不得对禅道 HTML 叠加旧 SDK 页面的 `default-src 'none'` CSP。保留禅道自身的必要脚本与表单功能，同时对 `api.php` 等非 `/sdk/` 根路径保持公网封锁。旧 IP 入口暂作回退通道，路径变化和现有 SSO 目标一并核对。

## 身份与安全边界

现有平台钉钉会话仍属于 `agent.orbbec.com.cn`，禅道脚本部署到同一主机与端口后与平台 API 同源。移除 SDK React 页面或增加路径层级都不能改变这一浏览器事实。切换需将禅道视为平台同等级别的受信应用：保持当前加固镜像和已知漏洞修补、限制禅道扩展与上传、保留禅道/平台双重权限与审计。该同源残余风险在发布记录中明确，不宣称路径隔离。

免密入口只为当前已准入员工建立会话，不使用共享 `sdk-api` 身份。会话生成失败、禅道不可达或创建结果不确定时停留在错误页，不回退到公开登录或重复建号。应用 API 的旧原生需求接口可暂保留供回退和内部读取，但 `/sdk/` 不再加载它们；下次清理须独立评估调用方。

## 验收与回退

隔离环境先验证：匿名 `/sdk/` 去钉钉登录；已登录且在 3D 研发中心的员工自动进入个人禅道中文界面；无 SDK 准入者被拒；需求、任务、Bug、用例、测试、版本、发布、附件、登出与深链接不脱离 `/sdk/`。确认 Q4 既有需求原位可见，不重复创建。

生产发布以先备份禅道数据库和数据卷、平台配置与当前代理配置为前置；先部署可回滚的应用与禅道配置，再在隔离 Nginx 容器验证候选配置，最后受控切换共享代理。绝不在生产机运行独立配置的 `nginx -t -c` 或 `nginx -T -c`。切换后核对 `/sdk/`、平台、行政入口及完整静态资源字节和权限错误日志。任何入口、资产或权限检查失败即恢复原代理路由及原禅道环境设置；不回滚业务数据。
