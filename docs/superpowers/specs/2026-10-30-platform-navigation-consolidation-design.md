# 平台入口与运行中心收敛

用户于2026-10-30讨论六项收敛并明确“开始重构”。按已讨论方案实施：隐藏平台AI助手/历史任务，区分正式Web服务与MetaBot渠道，合并运行概览和Agent状态，运行事件退出主导航，安全记录移入账号与权限。第4项按紧接讨论的“合并运行中心”执行。本次完成开发、验证、审查与主线整合，不将此前安全维护上线授权扩展为新界面生产发布。

## 基线与范围

代码起点 `4fa65dee6627f300eb97a93402417ed66b216a85`；此前实际平台发布为 `c6ee87f25e4562ee9ce84a4508491a3a089dbd4e` / image `sha256:baf2b448feecf41e1e437151c28296f3dc4ee4a443abac31c6c31824a0f2d1bf`。实际首页持久布局revision0仍包含数字化节点13个通用操作；只改变呈现，不重写其SQLite发布状态。保留其他会话的身份投影、状态展示、用户文件和所有专业Agent服务。

## 全局约束

- 只修改平台仓；不修改专业Agent业务代码、Loop、模型、预算、依赖、知识、数据库角色或业务记录。
- 目录权限继续由现有真实登录上下文和 `resolve_agent_use_decision_v41` 决定；隐藏入口不授予或撤销权限，不绕过服务自身认证。
- 暂停的是平台助手/任务的页面入口与交互；不删除后台执行组件、API或历史数据，不停止未知任务或更改飞书渠道。
- 不主动连接浏览器；接口和组件测试由开发侧负责，浏览器与生产验收单独登记。真实模型调用0、生产业务测试写入0。
- 独立工作区开发，逐任务审查，保留主线和用户未提交材料；无reset、force push、目录覆盖或其他工作树清理。
- 不修改或测试/重载生产Nginx，不部署生产服务。

## 正式Web目录契约

现有catalog仍用于历史Brain执行合同，HR在其中保留旧MetaBot适配字段；不通过重写这份执行合同来展示HR独立服务。新增独立的公开Web入口投影，在已经过滤授权的catalog卡片上增加：

```json
{"web_entry":{"kind":"independent_service","path":"/hr/"}}
```

当前发布清单准确为：`ai-fae-agent:/fae/`、`ai-daq-fae-agent:/daq/`、`hr-bot:/hr/`、`voc:/voc/`、`ai-admin-agent:/office/?view=services`。其余五个Marketing MetaBot卡片 `web_entry:null`。公共接口仍返回已授权卡片和原执行字段，新增投影不使任何人越权、不改变dispatchable或调度行为；入口必须是服务端固定发布表中的准确相对路径，拒绝任意URL/别名。此清单说明正式Web接入，不承诺即时健康。

前端目录、侧栏业务使用链接、全景业务动作共用同一受认证catalog投影及路径验证。客户端不得再用AGENT_ORDER充当准入名单，也不得以缺少新字段时回落到旧marketing路径。排序可有独立展示顺序，未排序的新合法卡片仍能显示。读取失败与真实空目录分别呈现；切账号/卸载中止旧请求，禁止迟到旧身份结果覆盖新身份。管理工作台权限仍与Agent使用权限区分。

## 页面和导航

- 收起 `/brain`、平台conversation、`/missions`及平台marketing页面的使用入口。旧地址显示功能暂未开放并提供正式Agent目录链接，不触发对话/任务API；后台数据和专业服务自己的对话页面保留。
- Agent目录只呈现正式Web投影的授权卡片，补上DAQ；HR直达独立 `/hr/`。不再展示MetaBot灰卡或助手空态引导。业务直达与管理入口分别标注，技术支持咨询与技术支持管理去向明确。
- `/admin`为唯一“运行中心”：保留现有总量、趋势、关注项，使用一份可点击的Agent清单进入现有详情。保留系统监控对象但与业务Agent分组，避免总量与列表重复统计。`/admin/agents`旧列表地址回到运行中心，子级详情/runtime地址不变，深链只高亮运行中心。
- 运行事件从主导航移除，完整事件页面继续由运行摘要和Agent详情进入；后台采集和已有筛选深链保留。
- 审计日志从主导航移除，账号与权限增加“安全记录”入口，展示现有GovernancePage内容。管理员权限和观察者可见性不扩大；原审计深链仍能阅读，侧栏归属账号与权限。审计采集/拒绝/持久化不变。
- 全景只保留与所选业务节点相关的正式服务动作（HR/FAE/VOC/行政），移除助手、历史任务及通用运维/管理菜单、重复工程笔记动作；工程笔记统一保留侧栏辅助入口。全景布局编辑、证据阅读、组织目录、保留视图/滚动及未保存输入保护保留。
- SDK、大制造、FAE/VOC管理、Agent设计和owner访问记录继续遵守原独立权限及访问方式。

## 验证与风险

先真实HTTP/API授权边界的本地自动化，再组件路由/渲染测试和前端构建。最小回归包含：未登录401、空授权、HR旧adapter但正式Web、DAQ补齐、Marketing无Web投影、恶意路径拒绝、旧字段缺失fail closed；目录/侧栏/全景同一入口来源；旧助手地址不启动请求；运行列表合并与详情深链；管理员/owner/观察者权限；审计按需加载及全景输入保护。接口身份提供方边界可用明确测试替身，不能称真实员工SSO或业务模型验收。

主要风险是catalog执行合同与Web发布事实混用、旧深链恢复暂停功能、全景隐藏视图造成重复加载、权限变更时显示过期授权。通过独立投影、明确页面状态和身份隔离测试验收。本次不新增静默fallback，不删除历史或必要能力来制造成功。
