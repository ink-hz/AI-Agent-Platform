# 历史任务的数据与页面职责

「历史任务」按当前账号展示平台保存的对话工作记录，使用 `/api/v1/conversations`，条目打开 `/conversations/:id`。以最近更新时间排序，显示标题、来源、已知执行状态及时间；无状态不推断完成。提供最近和已归档两类查询及有界分页。范围不包含所有独立子应用的外部任务库。

列表读取独立于 Brain 新任务入口开关。旧 `/api/v1/brain/missions` 随 Brain 功能开关未注册时，不能作为持续展示的历史入口数据源；本修复不启用旧执行功能、不迁移或回填数据。旧 Mission 深链接不在此次变更范围。

列表和游标由服务端绑定当前用户及查询范围。前端换账号/角色清空页面，快速切换取消旧请求，分页重复按 ID 合并；失败不能伪装成空列表。401 提示登录，403 提示无权读取，其他失败允许重试且不推断 Agent 服务健康。
