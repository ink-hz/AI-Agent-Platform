# Agent 设计阅读页

用户确认入口放在「AI 工作」。名称「Agent 设计」，独立页面 `/admin/agent-designs`，仅平台所有者和管理员可读，首篇为 AI-HR-Agent 当前目录的 HR总体架构设计.md。

页面保留平台左侧导航；内容区铺满导航栏右侧可用宽度，采用独立页面布局，不套用通用页面的 1240px 居中限宽；桌面外边距 24px、窄屏 16px。窄章节目录紧邻导航栏右侧，宽阅读正文占剩余空间。首篇默认打开，无空卡片和占位 Agent；多篇时在页头按 Agent 切换，无整页刷新。原文、表格、代码和 Mermaid 图保留，图复用现有安全渲染与放大组件。章节链接支持源文档显式锚点。来源信息折叠展示，保留原文“目标架构，未全部实施”的边界。

HR 文件是唯一维护来源。当前文件有未提交修改，按用户指出的当前版本制作原样快照，记录源 HEAD、内容 SHA-256、工作区修改标记与采集日期；不替用户提交 HR 仓库。提供显式同步命令，后续从源文件更新快照并随平台发布，不能声称实时同步。运行与构建不读取兄弟仓库、不使用跨仓库符号链接。正文由管理权限 API 返回，不放公开前端资源。

复用 ArticleMarkdown，只补可选的明确标题锚点映射，不启用原始 HTML；Markdown 中的脚本和危险链接不能执行。后端只允许登记文档 slug，验内容哈希，未知文档 404，读失败 503，不暴露本地路径。

验证：HTTP 身份与角色边界、无公开缓存、未知 slug、正文与源字节一致；组件的目录跳转、页面内切换、失败/撤权清理；全部 Mermaid 源解析以及生产构建。页面视觉由用户验收。
