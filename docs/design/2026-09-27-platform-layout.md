# 平台内页面统一布局

用户已确认统一内容起点、页面边距、紧凑标题栏、按钮和卡片样式，内部保留图表画布、目录与正文、管理列表等用途布局。独立跳转的 HR、行政、FAE、VOC 不在范围内；平台历史内嵌 HR/FAE 路由也不套用新外框。

公共外框拥有页面宽度和外边距：不再使用 1240/980/920px 的多重居中容器。桌面边距 24px，窄屏 16px；内容铺满导航右侧。阅读正文可以控制文本行长，但目录和标题不随正文居中。公共标题为 26px、说明 13px、右侧操作，去掉装饰英文和固定的大幅空白。源文档正文的标题层级不改。

普通页采用文档滚动；图表保持画布；AI 助手保持完整高度和内部滚动；工程笔记保持目录与阅读区独立滚动，Agent 设计保持长文档与粘性目录。二级目录采用统一浅蓝灰底、230px 宽、与正文间隔 24px。手机保留当前抽屉/折叠交互。安全过期提示、授权、来源说明和业务状态继续工作。

实现分工：platformLayout.ts 描述路由所属外框，platformLayout.css 管理公共尺寸、标题、阅读表面和表单控件；PlatformPageHeader 提供紧凑标题。页面只负责业务内容和动作，不另行设置整个页面居中宽度。

验收：路由类型包含正常页/阅读/画布/对话及独立应用排除；换路由不丢失导航偏好和授权环境，权限分区不新增请求/跳转，文档切换、SVG、目录与抽屉行为保留。运行相关组件回归及生产构建，独立审查后归并；生产版本再次核对才发布。真实浏览器布局由用户验收。
