# 账号与权限：管理员名单与搜索授权

用户已批准实施；随后明确页面和导航仍叫「账号与权限」，不改名。

默认页面只显示平台所有者及管理员，展示花名/目录显示名、部门和可用操作。所有者不可移除，普通平台管理员只读该名单。所有者通过「添加管理员」打开搜索区，输入目录中的花名/姓名后返回有限匹配结果，选定具体人员后授权。授权绑定 internal_user_id，不能直接把输入文本当授权身份；同名通过部门区分，仍不能辨认时提示而不猜选。目录显示名之外的加密实名不新增解密或索引。

默认请求仅返回管理员。候选搜索按需请求，空查询不返回全量成员；仅 active member 可新增，保留现有角色转换规则。后端提供部门名称投影；不返回手机号、邮箱或身份提供方标识。管理员撤销仍允许非活跃管理员；硬过期只读时禁止变更。已有审计、CSRF、操作幂等、结果不确定时的恢复均保留。

首页不再加载观察者、合作方或业务授权面板。观察者/合作方保留独立二级入口。FAE/VOC 权限作为业务工作台关联的独立授权页，侧栏对应业务入口旁为所有者提供权限入口。FAE 工作台另提供权限入口；VOC 的独立应用不在本次修改范围，权限页由平台承载。各授权页复用原组件及原授权边界。

默认页采用紧凑名单、右上添加按钮、按需搜索区；正常目录状态、范围占位、英文抬头和全局原因输入不出现在首页。其他授权页的现有业务规则保持不变。页面视觉由用户验收，开发侧运行 API、组件及构建检查。不执行生产授权变更，不自动部署。


实现状态：已实现，尚未部署。管理员名单与候选搜索使用现有 users 路由的独立 view，默认不传输全员；查询过宽或同名同部门无法区分时停止选择。观察者、合作方分别位于 `/admin/identity/observers`、`/admin/identity/partners`；FAE、VOC 授权页分别位于 `/fae/manage/access`、`/admin/voc/access`，在侧栏对应业务入口旁提供所有者可见的权限按钮。访问记录沿用账号权限类别，所有原写入权限仍由后端判定。
