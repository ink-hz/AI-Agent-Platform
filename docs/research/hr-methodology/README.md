# HR 方法论认知资源索引

本目录供 Agent 在理解用户输入后自主选择阅读。索引只说明资源能帮助思考什么，不规定关键词路由、必选方法、执行步骤、打分或结论。Agent 应结合本轮目标、已有上下文和证据缺口选择一份或多份资源，并在输出中保留不确定性。

| 资源 | 帮助理解的问题 | 相对路径 |
| --- | --- | --- |
| 岗位与业务情境 | 岗位为什么存在、关键任务是什么、能力要求从哪里来 | `job-and-context.md` |
| 要求校准与 AMO | 条件太多或长期招不到人时，问题可能在需求、供给、吸引力还是甄选 | `requirement-calibration.md` |
| 胜任力与人才画像 | 如何把抽象标签转成岗位相关、可观察的行为和发展层级 | `competency-and-profile.md` |
| 人才来源与能力迁移 | 如何跳出公司名单，判断跨行业、相邻岗位和应届生的迁移可能 | `sourcing-and-transfer.md` |
| 循证判断 | 如何区分事实、陈述和推断，评价多来源证据及冲突 | `evidence-informed-judgment.md` |
| 甄选与工作样本 | 如何理解结构化面试、工作样本、公平和一致性之间的关系 | `selection-and-work-samples.md` |
| 候选人比较与反馈 | 如何在同一岗位语境下比较不同证据，并从结果中形成可审阅学习 | `comparison-and-learning.md` |

来源的实际核验范围、页码和限制见 `../2026-09-08-hr-methodology-sources.md`。这些材料是思考支架，不替代岗位负责人判断、组织数据、候选人授权或适用法律审查。
