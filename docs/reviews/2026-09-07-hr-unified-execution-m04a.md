## 实施边界裁决

1. 仅注册实际 Claude 执行器和明确注册的运行时执行子进程，不新增任意后代进程的通用监管平台。外部副作用单独累计，不能以执行器停止代替无副作用证明。
2. 原生进程身份必须在发送冻结输入之前持久化。关闭迭代器、请求取消、租约过期、超时均不是退出证明；缺少证据保留占位。
3. 同一启动身份只发生 UID 改变，不能判定旧进程已退出。不同主机或无法读取身份的情形保持未知；不向可能被复用的 PID 发送信号。
4. 通过仍持有的 PTY 执行有界优雅退出并观察实际退出；不把 `/exit` 当业务输入，不新增 v5 PID 强杀回退。未选择 v5 生命周期的旧调用保持原行为。
5. `endRun(kind)` 不能仅凭终态名称释放已经领取的执行，也不能创建缺少对应 M03 源事件的终态。先原子提交唯一终态，再凭实际停止证据释放；较晚到达的旧证明不得释放新命令。
6. 私有心跳与用户可见进展分离。结果终态不可被后到的停止证明重写，也不能在终态之后追加心跳。
