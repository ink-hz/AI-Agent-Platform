# 岗位校准（临时）：本公司机器人动作生成模块 — 依澄清修正

性质：本公司测试岗位的临时校准，基于用户第2轮澄清（临时基准，非正式标准）。竞对归档（d10b5fff…）仅作对标参考，不移植其门槛。方法依据 requirement-calibration r2（AMO / 任务相关性 / 要求强度分层）。

一、本岗位真正要交付什么（据澄清修正）
交付物：可运行在实体机器人上的动作生成模块。当前处研发探索阶段，尚无线上 A/B 系统。
核心能力链：多条件动作生成 → 满足物理可执行约束（动力学、接触平衡、IK、拼接过渡）→ 能对生成结果做约束验证。表现力/风格类可控生成为方向性能力，非当前阶段主交付。
用人策略：允许有动作生成项目、但无真机经历者入职培养；成功标准是入职约三个月后能独立完成约束验证。因此"真机经历"是可培养项，不是入职硬门槛。

二、相对竞对原文的修正（保留改了什么）
1. 执行载体：原文实体机器人/数字人歧义 → 本岗位确认为实体机器人。纯图形/动画背景不再天然匹配，需看物理可执行性理解。
2. 线上A/B：原文职责4含"线上A/B与回归" → 本岗位无该系统，不作硬门槛；评测能力仍需要，但形态是离线/仿真的约束验证。
3. 真机经历：从"疑似要求"降级为"可培养、非入职门槛"，用三个月独立约束验证作为培养期验收点。

三、要求强度分层（待用户选择，非确认）
- 必备（入职即须、支撑核心交付）：动作生成/扩散或序列模型的实做能力；运动学基础（IK/约束、拼接过渡、抖动与不稳定的识别处理思路）；至少一个动作生成项目经历（Text2Motion/Speech2Motion/风格控制/韵律对齐任一）。
- 可培养（允许入职后达成，三个月验收）：面向实体机器人的约束验证独立能力（真机/动力学可执行性）。
- 加分：多模态条件（语音韵律/视觉）经验；表现力可控生成（风格/情绪/节奏）；跨 TTS/对话/控制/安全协作经验。
- 惯例/不作门槛：顶会论文；线上A/B实战（本阶段无系统）；要求全部四个方向都具备。

四、未知与边界（影响后续，需用人经理确认）
1. 机器人形态与自由度（人形全身 vs 上肢/手势为主）未定，影响运动学与安全约束的深度要求。
2. "独立完成约束验证"的具体验收口径未定：哪些约束（动力学/接触/安全）、用仿真还是真机、通过标准是什么。
3. 职级/年限与研究-落地取向未定（原文"工程师/专家"双头衔，本轮未澄清）。
4. 培养资源未定：是否有带教、真机与仿真平台可用，直接影响三个月目标可达性（AMO 中的机会维度）。
