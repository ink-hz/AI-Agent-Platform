# Revopoint 公开归档19岗（静态包）研发→交付链核心研究要点（收尾版，未展开完整报告）

范围声明：仅基于所选静态归档 19 个岗位身份全文（gwtd.html 观察于 2026-09-06T14:38:14Z，17 个「27秋招」；gwtd1.html 同日观察，2 个社招）。归档文本已通读（coverage_complete），但归档只说明观察时点的招聘表达，不能证明现行官网内容或组织实际运行状态。本次为预算收尾，只交付最能改变找人做法的三个判断与证据边界，不展开完整报告。

判断一：这份归档里存在两个不同劳动力市场，不能当成一个「3D 视觉/机器人团队」去搜。
gwtd1.html 的两个岗是社招且门槛写法完全不同：机器人路径规划工程师（f9893b40）要求「本科及以上电气/自动化相关专业，精通运动控制器」「3年以上工业机械臂开发经验」「掌握 Linux/WINCE 系统及 SPI、CAN 通信」；AI算法工程师（39006d7c）要求「2年以上算法经验」，职责含「点云分割、路径规划与运动控制」。而秋招 SLAM 岗（c401b56a）交付的是「视觉/激光前端跟踪、后端优化、回环检测与多传感器融合」「支持视觉定位与重建应用」。三者共用「点云/位姿」等词汇，但交付物分别是机械臂运动、模型迭代、视觉定位重建。找人做法的改变：f9893b40 的候选池在工业自动化/运动控制（总线、控制器、QT/VS 现场调试），用「3D 扫描/视觉算法」关键词搜会系统性错过；同时不能把秋招普遍的「硕士及以上」口径套到它的「本科及以上」上。反例与不可推出：39006d7c 写「协同部署团队优化模型」，这只证明存在一个部署对接方，不能推出公司已有在运行的机器人部署团队，也不能推出它与 SLAM 岗同团队——两者来自不同页面，无共同团队或项目标识。

判断二：客户侧支持的两个岗，硬性程度与教育门槛的方向和直觉相反，渠道要跟着改。
国内技术支持（e77e8d58）是「大专及以上」，三维扫描/逆向建模/3D打印实操经验与「全国职业院校技能大赛『产品数字化设计与制造』赛项参赛及获奖」写作「优先」；海外技术支持（d7ea90e6）是「本科及以上」，并把「具备三维扫描、光学测量或精密仪器相关行业的技术背景或实操经验」写在必需位（第3条），「有同类产品支持经验者优先」才是优先项。可执行含义：国内岗应主动进职业院校技能竞赛与相关实训渠道，若按本科筛简历，会把原文明确偏好的那类人先删掉；海外岗（限 2027 届海外留学生、不限国籍、英语工作语言）真正稀缺的是「留学生 + 光学/精密仪器动手经历」的交集，应把「同类产品支持经验」当加分而非门槛。另外 e77e8d58 的职责含「售前咨询、售中对接」「配合销售完成项目技术对接、方案协助、验收支撑」「样机调试、展会技术支持」——这更接近售前/方案角色，验证方式应是现场演示与故障诊断的工作样本，而不是按「售后」标签筛人。

判断三：多语种产品资料被写成内部自建能力，要招的是术语与版本治理者，不是译者。
产品资料文案策划（a2ab6bb6）职责含「借助AI工具和术语库完成多语种文档的翻译、校对和质量把控」「建立并维护文档模板、术语库、版本管理等规范」，要求含「可独立完成英文文档撰写或翻译」「熟悉AI大模型、机器翻译工具者优先」。找人做法的改变：面试用「把一段产品参数改写成面向用户的 FAQ/操作步骤」这类样本，比看语言证书更贴近任务。边界：「建立…规范」是对未来工作的期待，不能推出目前没有文档规范，也不能推出公司没有在用外部翻译供应商。

分工关系：有直接证据 vs 不能判断（要点）。有直接文本支持的：存在 PMC 职能与经理及内部采购、仓库对接方（8e9d916d「协助PMC经理」「推动采购与仓库解决」）；库存、成本、物流费用核对在内部财务岗（63496127）；独立站为自营运营（5eefbd9a「Shopify等的日常运营管理」）；短视频「跟拍及后期剪辑」在内部（eb01dc2e）；测试含用例、缺陷闭环与自动化探索在内部（bae11a6d）。不能判断的：整机是自建产线还是代工/外协（仅出现「设备故障」「供应链管理」，无归属信息）；广告投放与海外 PR 是否由代理承接——海外品牌专员（f362b550）负责「识别并开发KOL资源」「制定海外PR整体战略规划」，外部资源关系由内部岗管理，既不等于职能外包，也不能证明全内部；西安/深圳的职能分工（仅 8bb1c51e、63496127、e2e0a6e2 带地点，不足以判断站点定位）；光学/结构光硬件、嵌入式、机械结构能力归属——秋招 AI 算法岗（977c1fdc）提到「提升模型在嵌入式设备上的推理性能」，说明有嵌入式目标平台，但本归档无相应岗位，岗位缺席不证明能力缺失。
