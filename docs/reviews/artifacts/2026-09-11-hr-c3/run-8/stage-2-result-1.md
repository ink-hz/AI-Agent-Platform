# Revopoint 公开归档19岗（静态包）核心研究要点：研发到客户交付中在招什么问题解决者，哪些分工有直接证据

范围声明：仅依据所选静态归档正文（19 个岗位身份，两个来源页 gwtd.html 与 gwtd1.html，观察时点 2026-09-06），已通读全部职责与要求原文。归档自述"不代表企业当前全部岗位，也不能证明组织实际运行情况"，本文所有判断限于该时点的公开广告文本，不代表现行官网，也不描述实际组织。

一、最能改变找人做法的判断：客户交付端的承重能力是"能亲手把扫描仪用出结果"，而它的可验证代理不在名企经历里

国内技术支持（e77e8d58-b3c7-533a-9455-c54b84844df3）是全归档门槛最低的一条（"大专及以上学历"），但任务跨度最宽：售前咨询、售中对接、售后全流程，"配合完成样机调试、展会技术支持"，并要求"具备技术文档撰写能力，可独立完成技术资料整理"。它给出的优先项异常具体——"三维扫描、逆向建模、3D打印等相关项目实操经验或学科竞赛经历"、"全国职业院校技能大赛'产品数字化设计与制造'赛项参赛及获奖"。这说明用人方对这个岗位的能力判断是动手可验证的，而非学历或公司品牌。找人做法应随之改变：搜寻应指向职业院校技能大赛渠道、逆向建模/3D 打印实操人群与作品，评估应用工作样本（现场扫一个难件、写一份客户可读的问题定位说明），而不是筛学历或"同行业年限"。

海外技术支持（d7ea90e6-ee33-59f4-bb69-f71ddee42e09）看似同族，实为不同口径，不能共用筛选标准：它把"三维扫描、光学测量或精密仪器相关行业的技术背景或实操经验"写为必需，仅把"同类产品支持经验"列为优先；专业限定到机械工程/精密仪器等，并要求英语作为工作语言、参与海内外展会。也就是说，国内岗的扫描实操是可培养的优先项，海外岗的技术背景是并列必需项——把两者互换会直接招错人。

同一岗存在一处会改变筛选口径的原文冲突：中文要求写"2027届海外留学生"，英文写"Class of 2026/2027 International Graduates"。届别口径不一致，需要用人方确认后才能定投递与筛人范围。

二、大量"协助/配合/收集反馈"的措辞，说明在招的是增补执行位，不能据此推出已经运行的反馈闭环团队，也不能把这些任务升格为独立交付门槛

"客户反馈"这一动作被写进多个岗位：软件测试（bae11a6d-c71d-5ea5-aa58-3740e7ee70bf，"收集分析客户反馈，持续优化测试流程与方法"）、国内技术支持（"为产品优化提供信息"）、产品资料文案策划（a2ab6bb6-ed7f-5dc7-9805-c4f57945f4b3，"与研发、产品、市场、售后等部门协作，获取产品更新和客户反馈"）、国内销售（498a103e-4dd9-5042-9b0d-71bf16a72532，"分享市场反馈和客户意见，优化销售流程"）。共同词汇不能拼成一个已在运转的闭环团队；它只证明广告期待这些人各自把信息带回来。同时，项目管理-西安（8bb1c51e-d66f-5bb6-ae7d-fe40adca543e）写的是"协助项目经理"，生产计划专员（8e9d916d-2d95-51a1-981b-a31adbd59e7a）写的是"协助PMC经理完成生产订单拆解、排程编制"——承重责任人另有其人，这两岗是执行与跟单位。找人做法：面试应验证"信息不全、要跨部门催办时如何推动到闭环"的具体行为（可用情境化工作样本），而不是要求独立 owner 级履历；把"协助排程""收集反馈"写成硬性独立交付经验是对原文的加码。

三、自建/外采与分工：哪些有直接证据，哪些不能判断

有直接证据（自行承担该动作，岗位原文层面）：海外自有流量与内容链路——跨境电商运营（5eefbd9a-5bcb-55cd-925f-7e7ecdefdab7）负责"独立站（Shopify等）的日常运营管理"、广告投放与 SEO；海外品牌专员（f362b550-4363-5aeb-9395-0e9d95e94c49）自行"识别并开发海外社交平台的优质KOL资源"并"制定海外PR整体战略规划"；短视频策划剪辑（eb01dc2e-0989-53a1-bc37-f17bde1a0426）自行"跟拍及后期剪辑"；产品文档"借助AI工具和术语库完成多语种文档的翻译、校对和质量把控"（a2ab6bb6）。

有直接证据的外部关系（但不等于职能外包）：KOL 与国际媒体是外部合作资源；海外销售（918e443e-701b-53ae-8c0e-a8bcc855dca8）"建立和维护与海外合作伙伴的良好关系，共同开展市场推广、产品演示"；生产计划提到"推动采购与仓库解决"欠料；财务专员（63496127-4d6c-575e-96e0-d4ffcf1bdd4f）"核对物流运费及税费账单"。这些说明存在供应商、渠道伙伴与物流服务方，属正常外部采购。

不能判断：一是制造形态——"设备故障""生产订单拆解、排程"与"仓库"不足以区分自有产线还是代工；二是硬件、光学、结构、嵌入式研发由谁承担——归档中没有此类岗位，但归档自述范围有限，岗位缺席不证明没有其他承接方式（项目管理岗要求"光学、电子科学与技术、微纳制造"专业，反而是硬件流程存在的间接线索，仍非自建研发的证据）；三是 gwtd1.html 两岗（AI算法工程师 39006d7c-6a69-50ed-b71e-f0176f67a49d 的"路径规划与运动控制"、机器人路径规划工程师 f9893b40-e934-5109-bcb6-ae6b46df21f5 的"六轴机械臂路径规划"，均有年限要求）与秋招页 SLAM 岗（c401b56a-7268-5745-99c4-e5afd592febe）是否同一产品线或团队——两页来源不同、观察时点不同、人群不同，不能合并成一个机器人团队。

附一条影响搜寻口径的读法：SLAM 岗把前后端优化、多传感器融合、相机标定与立体匹配、2D 检测分割、新型三维表达写在同一岗，且第2条为"视觉或激光 SLAM 研发经验"（可替代背景，不可要求两者兼备），顶会论文/开源为优先项而非门槛。对扫描仪产品最直接承重的是标定与立体匹配、深度估计，建议与用人方确认承重段后再定搜寻画像，避免用论文数量代替能力。
