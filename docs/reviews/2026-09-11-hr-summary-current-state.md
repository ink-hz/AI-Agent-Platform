# HR 摘要请求当前状态修订

日期：2026-09-11。

上下文压缩请求原先只包含摘要指令与待压缩历史，没有携带当前获准目标、对象、精确选材和 checkpoint。预算续作后的模型因此可能仅凭阶段摘要理解任务范围。

本次在 `backend/app/hr_agent/context.py` 中复用普通工作请求的当前状态消息，作为摘要请求前缀。该前缀参与输入 token 与窗口计算，但不属于历史 entry，也不进入 `derived_from`。摘要保存时同时继承该输入修订的当前对象和冻结摘要请求 dependencies，避免仅在前缀出现的候选人或材料内容被保存成无作用域历史。历史权限筛选、工具集合、业务路由和 checkpoint 持久化均未改变。

真实数据库回归覆盖：实际持久化的 summary ModelRequest 包含当前状态；提交模型摘要后 checkpoint 不被摘要正文覆盖；公开旧历史压缩时，仅在当前前缀出现的候选人和材料仍成为摘要标签，切换候选人或撤销材料后摘要不可读；候选 A/B 历史隔离保持；前缀与输出预算导致窗口不足时进入 `waiting_budget`，不发送缺失上下文的摘要请求。
