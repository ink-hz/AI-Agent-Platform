## 实施范围

公司侧新增独立目录、详情和分页岗位接口，沿用 HR 使用授权和已有情报导入。公司详情保留本公司的原分析单元，以及摘要、事实、推断、建议、替代解释、未知项和置信度；推断的 claim_type 与各类原始 ID、依据关联不丢失。官网公开材料事实无需匹配岗位即可被读取。

使用真实 `company_key` 关联 schema 3 统计。缺失矩阵返回 null，不制造零值。目录和详情不加载岗位全集，不传生产请求、输入证据全集或模型用量；数据库层也先完成必要字段与公司范围的投影，避免应用拿到整库再丢弃。

当前目录只来自当前有效 bundle。详情和分页携带目录中的不可变 bundle 身份以保持阅读一致；普通新入口读取当前内容。移除当前发布后，普通目录为空，未固定的公司读取返回 404，已经打开的固定引用仍然可读。界面没有版本选择或历史报告主入口。

公司／专题两个根入口保持区分；完整专题及双向关联仍依赖 M1／M2／M3，不创建虚假专题。采集、分析生产、重新生成、发布与保留的方法论分支均未改变。

## 显式带入对话的实际边界

用户选择公司或具体内容后，选择显示在 HR 对话输入区，可查看、移除，保留原来的文字与附件，点击选择不发送。新对话和已有对话共用一个序列化函数，将所选摘要、完整选中结论或岗位范围以及固定引用作为用户选择的参考数据，加入用户实际发送的消息。

这沿用现有消息持久化与幂等契约，没有新增服务端可信知识声明字段。材料不因被选择而获得执行指令权；引用整体限制为 12 KiB UTF-8，最终输入同时遵守原 32 KiB 限制，超限明确阻止发送，不静默截断。失败可重试同一已固定输入，成功仅清理本次提交的选择。返回目标与选择按账号隔离。

该接入证明显式选择能够到达持久化任务输入，不等于普通对话中的自主情报发现、云端私有全文按需读取或实际模型推理质量已验证。这些运行时能力及完整专题仍需后续单独闭环。

## 真实数据与 HTTP 验证

采用原始 bundle `2b49ecc4-42fe-45ae-80ac-26891f42ac6c`：12 家公司、3437 个岗位、86 个分析单元。先调用现有校验器，再通过真实 v87 导入函数写入一次性 PostgreSQL；数据库使用仓库真实迁移和应用角色。

测试启动实际 `main.create_app` 和本机 Uvicorn HTTP，通过持久化 Web Session 与真实 HR grant 接收请求。外部登录与对象存储使用既有本地测试边界，不运行模型或执行 Worker，不向生产发送请求。

已验证：

- 12 个公司的独立摘要与正文七类字段逐项等于原产物；11 份矩阵完全对应，思看缺失矩阵保持 null。
- 官网文档等非岗位事实可达，原证据文件经接口下载后的 SHA-256 与引用一致。
- 公司范围、服务端分页、空筛选、错误参数及未知公司行为正确。
- 当前发布指针移除后，未固定访问与固定引用访问行为分别正确。
- 撤销真实 HR grant 后返回 403，匿名访问被拒绝。
- 前端客户端解析实际 HTTP 的目录、全部详情和岗位页；共享输入函数生成的选择文本经实际消息接口持久化，重复幂等键返回同一 turn，读取结果保留原文。

真实样本裁剪夹具及可复现提取程序位于 [hr_intelligence_company](../../backend/tests/fixtures/hr_intelligence_company/provenance.json)。没有为测试虚构 `_v2`、UUID 矩阵键、递增 schema 或专题关系。

## 审查与状态

公司 API、显式选择、页面分项复审及最终独立联合复审均已通过，没有遗留 Critical／Important／Minor。最后的运行代码提交为 `c279cdb`。审查推动修正了数据库窄读取、生产元数据隔离、账号隔离、引用标量转义、分页上限、启动契约、复合事实身份、响应范围校验、岗位等待状态、公司导航与目录最新性、失败重试、已有对话仅选材发送和固定原始证据入口。

当前阅读以固定 bundle 保留；新公司链接等待最新目录成功返回，目录移除公司、204 或读取失败均不会回退旧包。重复点击当前公司保留正文与岗位状态；详情尚未返回时回到目录会中止请求、结束加载，并忽略迟到响应。延迟时序回归先复现失败，再验证修复。

真实浏览器通过一次性账号访问实际应用的构建产物，已验证公司搜索、影石独立正文、核心判断优先和统计默认折叠、依据展开、岗位 1–25 与 26–50 分页、南京筛选 1–11 / 11、岗位职责和任职要求。带入南京岗位范围后进入未发送草稿，查看和移除选择均正常；返回情报保留公司搜索、南京筛选、依据与岗位展开状态，并停留在离开时的岗位列表底部；再次返回对话仍保留输入文字。专题显示明确的暂不可用说明。

浏览器只验证阅读与草稿交互，没有点击发送；消息持久化由上述真实 HTTP 测试验证。预览使用仓库既有本机代理，转发至持久化测试会话，不验证 SSE 或实际 Agent 推理。首次预览因五分钟测试时限结束，未计为通过；修正后完成交互并主动释放预览，整条真实 HTTP 测试通过（1 passed，126.02 s，含人工页面检查等待）。
