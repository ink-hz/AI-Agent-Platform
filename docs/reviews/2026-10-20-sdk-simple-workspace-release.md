## 仍需业务方验收

- 按仓库 `AGENTS.md`，员工在钉钉浏览器中实际点击四个入口、填写需求或任务、确认表单体验和个人操作归属，由业务方最终验收。开发侧没有冒用个人身份写业务数据。
- 禅道已经打开的浏览器会话在目录撤权后是否即时退出未被证明；平台会即时拒绝新票据，后台正常轮询最多约五分钟同步禅道组与产品白名单。目录硬过期时停止新票据，但不批量撤销现有禅道权限。
- 私有产品白名单接口是全量更新。平台服务账号是该白名单的预期唯一写入者；管理员同时手工修改会有并发覆盖风险。

## 回滚

原环境文件、控制库和禅道转储及原 API 配置在上述私有备份目录。若 API 出现回归，先关闭 `PLATFORM_SDK_AUTO_PROVISION_ENABLED` 并恢复原 `platform.env`，使用备份 `api-inspect.json` 记录的原有 14 份 Compose 文件和原 API 镜像 `orbbec-agent-platform:f864dc9691ff3b8736ea5f662ff9a263cabebbe9` 仅重建 `platform-api`。迁移 119、120 为向前兼容的加法迁移，应用回滚不删除表或已有账号；禅道服务账号可禁用而无需还原整库。生产 Nginx 配置未变化，无代理回滚动作。
